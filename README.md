# Human Capital Management System (HCMS)

A portfolio-ready Human Capital Management System designed to demonstrate end-to-end HR workflows, employee administration, attendance management, leave approvals, payroll operations, and role-based user access.

## Overview
This project includes a full-stack HR platform built with React + TypeScript on the frontend and Node.js + Express on the backend. The public version is sanitized for portfolio sharing and intentionally excludes any production secrets, employee records, or live organizational data.

## Features
- Employee and department management
- Organizational structure and role-based access
- Attendance and leave workflows
- Overtime and payroll support
- Audit and compliance-related admin controls
- Portfolio-ready frontend and backend architecture

## Tech Stack
- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Node.js, Express, TypeScript, Sequelize
- Database: MySQL
- Deployment: Render-friendly configuration

## Notes
This repository is sanitized for public sharing. It does not include real credentials, database dumps, or production employee data.

## Local Setup
1. Install dependencies for both frontend and backend.
2. Configure local environment variables using the example templates provided in the project.
3. Create a local MySQL database for demo use.
4. Run the frontend and backend services.
